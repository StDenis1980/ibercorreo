# Asset attribution

Every non-code asset in this repository is listed here with its author, source and licence. `cargo xtask assets` (part of `cargo xtask ci`) fails if an asset file is missing from this table.

**Policy (mandatory):** Iber Correo contains **no Microsoft (Outlook, Office), Apple, Google, Mozilla or other vendors' iconography, images, templates, themes, sounds or fonts**. Every asset is original work by IberOffice contributors or third-party material under an open licence (OSI open source, public domain / CC0, or a Creative Commons licence that allows redistribution). Screenshots of other vendors' software are never committed. Fonts go to [storytold/craft-fonts](https://github.com/storytold/craft-fonts), never this repository.

Generated-in-code art is original and has no file to list: the UI icons (`crates/ui-egui/src/icons.rs`), the theme colours (`crates/ui-egui/src/theme.rs`) and the sample mailbox (`crates/engine/src/sample.rs`).
